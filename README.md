# 한아련 삼국지 API 공약 — 사용 설명서

바닐라 HTML/CSS/JS + Supabase + Cloudflare Pages 구성.
**빌드 도구 없이 파일만 올리면 바로 뜹니다.**

---

## 2. 배포 순서 (딱 3단계)

### ① Supabase — SQL 한 번 실행
1. 프로젝트 `guonejbrlhfaammdcwrf` → 왼쪽 **SQL Editor**
2. `supabase_전체.sql` 전체 복사 → 붙여넣기 → **Run**
3. 표 10개가 생기고 **지금 화면에 보이는 내용이 그대로 DB에 심어집니다.**

> 여러 번 실행해도 안전해요 (이미 있는 건 건너뜀).

### ② GitHub — 폴더 그대로 업로드
위 구조 그대로. **`fx.js`·`style.css`·`supabase.js`는 루트에** 둬야 합니다.

### ③ Cloudflare Pages
Connect to Git → repo 선택 → **Framework preset: None** (빌드 명령·출력 폴더 전부 비움) → Deploy.

배포 후 관리자는 `배포주소/admin/` 으로 접속. 비밀번호는 **`9781`**.

> ⚠️ 관리자 비밀번호는 소스에 그대로 보입니다. **버리는 비번**만 쓰세요.
> 바꾸려면 `admin/index.html` 안 `var ADMIN_PW = '9781';` 한 줄만 수정.

### SOOP 게시글에 넣을 때
```html
<iframe height="2400" scrolling="no" src="배포주소" style="width:100%;border:0;display:block;"></iframe>
```

## 3. 관리자 페이지 — 탭별 안내

| 탭 | 고칠 수 있는 것 |
|---|---|
| 🏠 사이트 | 탭 제목, **파비콘 주소**, **화면 전환 연출(프사·앞말)**, 공유 설명, 인장 글자(吳)·영문, 사이드바 하단 문구, **목차 6칸 한글/영문**, 문의 모달 문구 전부(버튼·라벨·안내글·알림 문구까지) |
| 👗 컬렉션 | 의상·헤어 항목 추가/이름/이미지 주소/순서/삭제 + 섹션 문구 + `LOOK` 글자 + 빈 목록 문구 |
| 🎲 룰렛 | 확률표 항목·확률, 섹션 문구, 배지(기본 비어 있음), 각주(기본 비어 있음), **한 열에 몇 개씩**, 가운데 마스코트 이미지 |
| 📜 누적공약 | **현재 누적 개수**(→ 진행바·달성 배지 자동 계산), 공약 목록, 진행바 라벨·배지 글자 전부, **글자 크기(px)** |
| 🎁 개인보상 | 개수 문구 · 보상 내용 목록, **글자 크기(px)** |
| 📦 누적보상 | 구간 추가 → 구간 안에 상품 추가 (2단 구조) |
| 🏆 TOP5 | 보상 이름 · 이미지(비우면 번호로 표시) |
| 📖 보상기록 | **시청자 단위 관리** — 한 사람에게 보상 여러 건, 건별 **전달 완료 체크**, SOOP 아이디(프사 자동 연동), 검색칸·배지 문구, 빈 화면 도장 글자 |
| ✉️ 문의 | 사이트에서 들어온 문의 확인 · 삭제 |
| 🎨 테마 | 색 6종 — 주색·강조색·금박·형광·먹색·종이색. 나머지 색은 자동 계산. 형광은 카드 주사선·패널 우측 실선 등에 적용 |

### 사이트에서 되는 것
- 보상기록은 **업보 방식** — 시청자가 카드 격자로 깔리고, 카드를 누르면
  그 사람이 받은 보상 목록이 모달로 열립니다.
  닉네임 또는 SOOP 아이디로 **검색**할 수 있습니다.
- 관리자에서 **전달**에 체크한 보상은 모달에서 **빗금**이 그어집니다.
  전부 전달된 시청자 카드에는 `畢` 도장이 찍힙니다.
- 보상기록에 **SOOP 아이디를 넣으면 그 사람 프사가 자동**으로 옆에 뜹니다.
  주소는 `profile.img.sooplive.co.kr/LOGO/{앞 2글자}/{아이디}/{아이디}.jpg` 규칙으로 만들어져요.
  아이디를 비우면 닉네임만 나오고, 사진을 못 불러와도 닉네임은 그대로 보입니다.
- **이미지를 누르면 크게** 보입니다 (의상·헤어, 누적보상 상품, TOP5 보상).
  닫기는 ✕ 버튼 · 바깥 영역 클릭 · `ESC` 아무거나.
  확대창의 설명 글은 각 항목의 **이름**이 그대로 쓰입니다.

### 보상기록 다루는 법
1. **➕ 시청자 추가** — 닉네임 + (선택)SOOP 아이디 + 첫 보상 1건을 넣습니다.
2. 목록에서 **관리** 버튼 → 모달에서 그 사람 보상을 계속 추가하고, 건별로 **전달** 체크를 켜고 끕니다.
   체크하면 관리자 목록에서도 빗금이 그어지고, 사이트 모달에도 그대로 반영됩니다.
3. 같은 SOOP 아이디(아이디가 없으면 같은 닉네임)로 추가하면 **자동으로 그 사람 밑에 합쳐집니다.**
4. 보상 내용·상태는 고치면 바로 저장. 닉네임·아이디만 **이름 저장** 버튼을 눌러야 하며, 그 사람 보상 전체에 한 번에 반영됩니다.
5. 목록의 🗑은 **그 시청자의 보상 전부**를 지웁니다. 1건만 지우려면 관리 모달 안의 🗑을 쓰세요.

### 조작 규칙
- **표 안의 값은 고치면 바로 저장**됩니다 (따로 저장 버튼 없음).
- **▲▼** 로 순서 변경, **🗑** 로 삭제.
- 카드 안 **문구**들은 아래 **저장** 버튼을 눌러야 반영됩니다.
- 저장 후 **사이트를 새로고침**하면 보입니다 (Ctrl+Shift+R).
- **칸을 비우고 저장하면 그 요소가 화면에서 사라집니다** (룰렛 배지·각주 등).

## 4. 화면 글자는 전부 고칠 수 있음

관리자에서 편집 가능한 문구 **94개** + 색 **6개**.
버튼 글자, 표 머리, "아직 등록된 항목이 없어요" 같은 빈 화면 안내,
"달성 / 다음 / 대기" 배지, `LOOK 01`의 `LOOK`, 알림 문구까지 전부 포함입니다.

**하드코딩된 글자는 0개** — 관리자에서 못 고치는 문구는 없습니다.

## 5. 이미지 넣는 법

이미지는 파일 업로드가 아니라 **주소(URL)만** 넣습니다.

1. **레포에 같이 올린 파일** → `/characters/look-01.webp` 처럼 **슬래시로 시작**
2. **SOOP 비공개 게시판에 올린 사진** → 이미지 **우클릭 → 이미지 주소 복사**
   (게시글 주소 말고 `https://stimg.sooplive.com/...` 로 시작하는 직접 주소)

권장 비율
- 의상·헤어: **세로 3:4** (900×1200)
- 보상 상품: 가로 3:2 정도
- 룰렛 마스코트: **정사각형 + 배경 투명 PNG**

## 6. 자주 나는 문제

| 증상 | 원인 / 해결 |
|---|---|
| 저장했는데 사이트에 안 보임 | 캐시 → **Ctrl+Shift+R** (그래도 안 되면 시크릿 창) |
| 추가가 안 되고 실패 알림 | SQL을 아직 안 돌림 → `supabase_전체.sql` 다시 Run |
| 관리자 상단에 "Supabase 미설정" | `supabase.js` 상단 2줄 확인 (지금은 채워져 있음) |
| 이미지가 X로 깨짐 | 게시글 주소를 넣음 → **이미지 직접 주소**로 교체 |
| 다크로 바꿔도 새로고침하면 풀림 | 정상 아님 — 브라우저가 localStorage를 막고 있는지 확인 |
| 순서가 이상함 | ▲▼ 로 조정. 누적공약은 **숫자값 오름차순**이어야 진행바가 맞음 |
| 룰렛이 한 줄로만 나옴 | 항목이 `한 열에 몇 개씩` 값보다 적어서. 기본 5 → 10개 채우면 5·5로 나뉨 |
| 전환 화면에 프사가 안 뜨고 글자만 뜸 | 이미지 주소가 잘못됨 → 🏠사이트 탭 `전환 화면 이미지` 확인 |
| 전환 연출이 아예 안 나옴 | 기기의 **'동작 줄이기'** 설정이 켜져 있으면 자동으로 생략됩니다 |
| 보상기록 프사가 안 뜸 | 아이디 오타 / 그 계정에 프사가 없음. 관리자 표의 **프사 칸**에서 바로 확인 가능 |
| 보상기록에 아이디 칸이 없음 | SQL을 다시 Run 해주세요 (`soop_id` 칸을 추가하는 문장이 들어 있음) |

## 7. 링크 미리보기(카톡·X 썸네일) 바꾸기

카톡·X에 링크를 붙였을 때 뜨는 제목/설명/이미지는 **관리자가 아니라 `index.html` 상단의 메타 태그**를 읽습니다.
크롤러는 JS를 안 돌리기 때문에, 관리자에서 제목을 바꿔도 **미리보기는 안 바뀝니다.**

```html
<meta property="og:title" content="한아련 삼국지 API 공약">
<meta property="og:description" content="삼국지 API 공약에 관한 모든 것을 한눈에 확인하세요.">
<meta property="og:image" content="/og-v2.jpg">
```

- 이미지를 바꿀 땐 **파일명도 같이 바꾸세요** (`og-v2.jpg` → `og-v3.jpg`).
  같은 이름이면 카톡이 예전 이미지를 캐시해서 계속 옛것이 뜹니다.
- 권장 크기 **1200 × 630**, 1MB 이하.
- 이미지 주소는 **`/og-v2.jpg` 처럼 슬래시로 시작하는 상대경로**로 두세요.
  도메인을 직접 적으면 오타 하나에 이미지가 통째로 안 뜨고, 나중에 도메인을 바꿔도 깨집니다.

**미리보기가 안 바뀔 때 순서대로 확인**
1. 브라우저에서 `배포주소/og-v2.jpg` 를 직접 열어본다 → **안 뜨면 파일이 업로드가 안 된 것**
2. 카카오는 캐시 초기화: `https://developers.kakao.com/tool/debugger/sharing`
3. 디스코드는 캐시가 오래 남습니다. 주소 뒤에 `?v=2` 를 붙여서 공유하면 새로 읽어옵니다
   (`배포주소/?v=2` — 사이트는 똑같이 열립니다)
